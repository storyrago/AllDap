## 4. 다음 사람이 밟을 함정

- **코랩에서 오류로 멈춘 뒤에는 런타임 > 세션 다시 시작 후 모두 실행한다.** 같은 커널에서 이어 돌리면 멈춘 모델이 GPU 에 남아 다음 모델이 "메모리 부족" 으로 잘못 건너뛰어진다. 그때 생긴 `{모델}_skipped.json` 도 먼저 지운다. 지우지 않으면 노트북이 그 모델을 다시 시도하지 않는다.
- **M4 같은 일반 지시 모델은 점수를 `[n]` 으로 쓴다.** 동결한 읽기 규칙으로는 못 읽음이 된다. 다시 돌리기 전에 규칙을 넓힐지 먼저 정하고, 정한 것을 출력 보기 전에 커밋한다.
- **M2(24B)는 이 노트북의 설정(4비트, fp16, `device_map='auto'`)으로는 T4(16GB)에 올라가지 않았다.** 올리기 전 GPU 점유 0.01GB 에서도 실패했으니 앞 모델이 남긴 메모리 탓은 아니다. 모델 크기와 설정 중 어느 쪽이 결정적인지는 가르지 않았다.
- 노트북에 리뷰 지적 두 개가 남아 있다(이번 실행 판과 갈라지지 않게 실행 중에는 고치지 않았다). 예외가 이어졌을 때 앞 예외의 기록이 모델을 붙잡는 경로, 그리고 가짜 사례 관문이 같은 글자 반복 같은 출력 붕괴를 잡지 못하는 것. 고치면 이번 실행 판과 다르다는 것을 커밋으로 나눈다.
