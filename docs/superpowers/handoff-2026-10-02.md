## 4. 다음 사람이 밟을 함정

- **워크트리에서 `docker compose up -d` 를 하면 이름이 충돌한다.** 폴더명이 compose 프로젝트명이 되므로 워크트리에서는 다른 프로젝트로 인식되어 `alldap-db` 컨테이너 이름과 겹친다. 원래 저장소에서 이미 떠 있으면 건너뛴다.
- **Spring 의 상태 확인 주소는 8080 이 아니라 `localhost:8081/actuator/health` 다**(`application.yaml` 의 `management.server.port`).
- `rank_trace` 실행 맨 앞에 토크나이저 정규식 경고(`fix_mistral_regex`)가 뜬다. 순위에 영향이 있는지는 확인하지 않았다.
