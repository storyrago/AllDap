## 1. 리포트가 스스로에 대해 거짓을 적고 있었다

리포트 5-7 절이 2026-09-12 까지 이렇게 적고 있었다:

> **Grafana 브라우저 렌더링이 안 된다.** 서버(`/api/ds/query`)는 정상이고 Prometheus 타깃도
> 둘 다 `up` 인데 대시보드 화면에 패널이 0개다.

🔴 **거짓이었다. 사람이 진짜 브라우저로 열자 패널 22개가 축·범례·데이터까지 전부 그려졌다.**

배제된 후보를 순서대로:

| 의심한 것 | 실측 |
|---|---|
| `schemaVersion` 불일치 | 39. Grafana 11.5.1 정상 입력 범위 |
| row 접힘 | row 5개 **전부 `collapsed: false`** · `nested: 0`. 최상위에 22개가 평평하게 |
| datasource UID 불일치 | 패널·타깃 어디에도 `datasource` 키가 **없다**. 전부 기본값으로 풀린다 |
| 프로비저닝 경로 | Grafana 내부 SQLite 에 **패널 22개 그대로 저장돼 있다** |
| 컨테이너 로그 | `starting to provision` → `finished to provision`. 파싱 에러 0건 |

🔴 **결정타는 따로 있었고, 그 사실은 이미 저장소에 적혀 있었다.**
`HANDOFF-2026-09-11.md:234` 이 *"손대지 않은 기존 대시보드도 같았다"* 고 기록해 뒀다.
**바꾸지 않은 대시보드가 같이 깨졌다면 원인은 대시보드가 아니다.** 그 한 줄이면
JSON 원인설은 그때 이미 끝났는데, 리포트를 쓸 때 아무도 그것을 읽지 않았다.

**안 그려진 것은 Grafana 가 아니라 그때 화면을 읽은 자동화 브라우저였다.**

### 이 저장소의 상습 부류 중 "정상을 실패로 부르는 검사" 의 네 번째다

앞의 셋(S3 `recorded_total` 무효 판정 · provenance 거짓 경보 · `__pycache__` 함정)과
**대가의 종류가 다르다.** 앞의 셋은 판을 한 번 더 돌리게 만들었지만, 이번 것은
**리포트에서 그림이 통째로 빠지게 했다.** 그리고 그 빈칸의 원인을 리포트 자신이
틀리게 적어두는 바람에, **읽는 사람이 스스로 고칠 단서를 잃었다.**

⚠️ **그때 실패했던 자동화 브라우저 경로가 지금은 되는지는 확인하지 않았다.**
PR 의 주장은 "원인이 그쪽" 까지이고 그 자동화를 고치는 것은 범위 밖으로 뒀다.

## 4. 새로 나온 도구 결함 하나

🔴 **`s2_probe._k6_start_epoch` 가 macOS 에서 항상 `None` 이다.**
`ps -o etimes= -p <pid>` 를 쓰는데 **BSD/macOS 의 `ps` 에는 `etimes` 가 없다**(`etime` 만 있다).
그래서 `k6_start_epoch`·`stage_offset_s` 가 null 로 찍히고 fold 가 오프셋 0 으로 접는다.

5d 는 관측기를 k6 와 0.07초 차이로 띄워 오프셋 0 이 **실제로 맞았기 때문에** 무해했다.
그러나 **"오프셋이 0 이다" 와 "오프셋을 읽지 못했다" 를 구분해주지 않는다.**
아홉 번째(단계 라벨 13.6초 밀림)를 사후에야 알게 된 경로가 여기일 가능성이 크다.
경고가 stdout 으로 나가 리다이렉트되면 버퍼에 갇히는 것도 겹친다(5d 의 `probe.log` 가 0바이트).

**고치지 않았다. 별도 슬라이스다.**

곁다리: `observability/grafana/provisioning/datasources/prometheus.yml` 에 `uid` 선언이 없어
Grafana 가 매번 임의 생성한다. 지금은 패널이 데이터소스를 명시하지 않아 무해하지만,
**누가 패널에 UID 를 하드코딩하는 날 깨질 자리다.** 역시 안 고쳤다.

## 7. 분배 방식에 대한 메모

앞 문서 §6 의 규칙을 그대로 썼고 이번에도 들어맞았다. 새로 확인된 것 둘:

- 🔴 **조사를 나눌 때는 "같은 자원을 누가 만지는가" 로 자를 것.** A(Prometheus)와 B(Grafana)가
  같은 obs 스택을 쓰므로, A 에만 컨테이너 기동 권한을 주고 B 는 **멈춘 컨테이너에서도 되는 일**
  (JSON 정적 분석 · `docker logs` · SQLite 사본)로 범위를 잘랐다. 양쪽이 재시작하면 서로의
  관측을 깨뜨린다.
- 🔴 **의심받는 도구로 그 도구를 검증하지 않았다.** 5d 브리프에 *"스크린샷을 자동화 브라우저로
  찍지 말 것"* 을 명시했다. 그것이 바로 용의자였기 때문이다. 세션은 **못박은 시간 범위가 든
  URL 까지만** 만들고 화면 확인은 사람이 했다.
